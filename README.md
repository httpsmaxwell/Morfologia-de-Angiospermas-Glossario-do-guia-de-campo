# Morfologia de Angiospermas · Glossário

Glossário online do guia de campo **Morfologia de Angiospermas**, de Ranna Costa e Veridiana V. Scudeller (2026). São 236 verbetes de botânica, organizados pelos seis capítulos do guia: Semente, Raiz, Caule, Folha, Flor e Fruto.

🌐 **Ver online:** https://httpsmaxwell.github.io/Morfologia-de-Angiospermas---Gloss-rio-do-guia-de-campo/

## Recursos

- Busca de termos em tempo real
- Verbetes agrupados por capítulo, com o número da página do guia onde cada termo aparece
- Modo claro e escuro
- Layout responsivo para computador e celular
- Link para baixar o guia completo em PDF

## Estrutura

```
Morfologia-de-Angiospermas---Gloss-rio-do-guia-de-campo/
├── index.html    # Glossário completo (HTML, CSS e JavaScript embutidos)
└── README.md
```

Não há etapa de build nem dependências locais. Basta abrir o `index.html` no navegador.
